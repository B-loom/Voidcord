What Voidcord does

Accounts and bots together

Sign in by email, by account token or by bot token. Captcha and two-factor handled.

As many accounts as you like

Each in its own window and its own session, sorted between users and bots.

Game detection

The game you are playing shows on your profile, without the official client.

Message editor

Embeds, buttons, files and an emoji catalogue, for bots.

In French, or in English

The interface, the plugins and the error messages follow the language you choose.

Updates

Voidcord tells you when a version is out, downloads it and installs it on restart.

Installing

  1. Download Voidcord-win-x64.exe with the button above.
  2. Run it. Windows will show a warning, the application not being signed with a paid certificate: go through More info, then Run anyway.
  3. Choose the install folder. That's all.

Read this before using Voidcord

A third-party client goes against Discord's terms of service.

Logging in with a user account from anything other than the official client can get that account disabled. Bots use the official API and do not have this problem.

No responsibility is taken.

Not for a banned account, not for a deleted bot, not for lost data, not for anything else. You use it at your own risk.

Voidcord is not an original project.

It is a modified version of aiko-chan-ai/DiscordBotClient, which deserves all the credit for the underlying work. When Discord changes and the client breaks, the fix is awaited from the original project before being carried over here.

A bug, a question?

Everything happens on the Discord server. For a bug, say what you were doing, what happened, and whether you were signed in with an account or with a bot: the two do not follow the same path through the application, and the answer depends on it.
